# الوضع الإنساني - اليمن

تقرير إنساني يومي عن النزوح في اليمن (نسخة عربية وتركية وإنجليزية)، لجمعية Güzel Eser İnsani Yardım Derneği.

صفحة ويب واحدة مستقلة (`index.html`) — تعمل بدون خادم أو اتصال إنترنت (كل الأصول مضمّنة داخلها: الصورة، الشعار، الخطوط، ومكتبة التصدير).

## الميزات

- تصميم مطابق تمامًا للملصق الأصلي (صورة خلفية حقيقية مع تدرج لوني، بطاقات، أيقونات) بثلاث لغات: عربي، تركي، إنجليزي.
- **الأرقام قابلة للتعديل مباشرة** بالنقر عليها (الإجمالي، عدد الأسر، عدد المحافظات، أرقام الضرر، التاريخ، ومحافظات النزوح) — تُحفظ تلقائيًا **لدى كل من يفتح الرابط** (وليس فقط في متصفحك)، مع زر لاستعادة القيم الأصلية للجميع. النص يلتف تلقائيًا داخل حدود البطاقة مهما طال.
- **تصدير صورة PNG** لكل لغة بدقة عالية.
- **تصدير PDF** عبر حوار الطباعة في المتصفح (كل لغة بصفحة PDF منفصلة بمقاس A4 بدون هوامش).

## البنية

- `index.html` — الملف المنشور فعليًا (هذا ما يُستضاف على Vercel).
- `api/data.js` — دالة خادم (Vercel Serverless Function) تحفظ التعديلات المشتركة بين كل الأجهزة، باستخدام GitHub كقاعدة بيانات (ملف `data/report-data.json` في هذا المستودع نفسه).
- `src/build_site.py` — السكربت الذي يولّد `index.html` من التصميم الأصلي.
- `src/design-source/` — ملف التصميم الأصلي (.dc.html) المُصدَّر من Claude Design.
- `src/assets/` — الصورة الأصلية، الشعار، ملفات الخطوط، ومكتبة html2canvas — يحتاجها `build_site.py` لإعادة التوليد.

لإعادة توليد `index.html` بعد أي تعديل على `src/build_site.py` أو التصميم المصدر:

```bash
cd src
python3 build_site.py
```

## تفعيل الحفظ المشترك بين الأجهزة (خطوة لمرة واحدة)

بدون هذه الخطوة، التعديلات تبقى محفوظة في متصفح كل شخص فقط (كالسابق). لتفعيل الحفظ لدى الجميع:

1. أنشئ **GitHub Personal Access Token** (من إعدادات حسابك على GitHub → Developer settings → Fine-grained tokens) بصلاحية **Contents: Read and write** على مستودع `MO3CODE/insani_durum` فقط.
2. في لوحة تحكم Vercel لمشروع `insani_durum`: **Settings → Environment Variables**، أضف:
   - `GITHUB_TOKEN` = التوكن من الخطوة السابقة.
   - `EDIT_PASSWORD` = كلمة مرور من اختيارك (تُطلب من أي شخص يريد التعديل، لحماية البيانات من التخريب — يمكن تركها فارغة لتعطيل الحماية).
3. أعد نشر المشروع (Redeploy) بعد إضافة المتغيرات.

بعدها، أي تعديل على أي رقم يُحفظ تلقائيًا لدى الجميع (مع شريط حالة صغير بجانب زر "إعادة الأرقام الأصلية" يوضح نجاح الحفظ من عدمه). إذا تعذّر الوصول للخادم (لا إنترنت، أو لم تُضبط المتغيرات بعد)، يستمر الحفظ محليًا فقط دون أي عطل بالموقع.
