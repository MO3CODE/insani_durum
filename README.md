# الوضع الإنساني - اليمن

تقرير إنساني أسبوعي عن النزوح في اليمن (عربي وتركي وإنجليزي)، لجمعية Güzel Eser İnsani Yardım Derneği.

صفحة ويب واحدة مستقلة (`index.html`) — تعمل بدون خادم أو اتصال إنترنت (كل الأصول مضمّنة داخلها: الصورة، الشعار، الخطوط، الأيقونات، ومكتبات التصدير).

## الميزات

- **لوحة إدخال موحّدة** («✎ تعديل البيانات»): تكتب الأرقام مرة واحدة فتظهر في اللغات الثلاث بالتنسيق الصحيح لكل لغة (2,349 / 2.349، أسماء الأشهر، أسماء المحافظات مترجمة). المحافظات تُختار من قائمة ويُحسب عددها تلقائياً. المعاينة تتحدّث أثناء الكتابة.
- **قسم «معدل النزوح»**: أربع نسب (المساعدات الغذائية، المأوى، الدعم النقدي، المواد غير الغذائية) بعنوان قابل للتعديل في كل لغة.
- **شريط أدوات** بتبويبات للغة (العربية / Türkçe / English / الكل) وللمقاس (A4 / منشور 4:5 / ستوري 9:16).
- **أرشيف التقارير الأسبوعية** (من زر التاريخ أعلى الصفحة): كل أسبوع يُحفظ كتقرير مستقل، و«+ تقرير الأسبوع الجديد» يبدأ من أرقام آخر أسبوع بتواريخ الأسبوع التالي.
- **التصدير**: PDF للطباعة (A4)، صورة PNG، منشور إنستغرام/فيسبوك 1080×1350، ستوري 1080×1920 (مع رمز QR لموقع الجمعية)، و«تنزيل الكل» في ملف ZIP واحد (3 لغات × 3 مقاسات).
- **الحفظ المشترك**: كل حفظ يصل لكل من يفتح الرابط. إن تعذّر الاتصال يبقى التعديل في الجهاز مع تنبيه واضح وزر «إعادة المحاولة».

## البنية

- `index.html` — الملف المنشور فعليًا (يُولَّد، لا يُعدَّل يدوياً).
- `api/data.js` — دالة خادم (Vercel Serverless Function) تحفظ التقارير في `data/reports.json` داخل هذا المستودع عبر GitHub API. نسخ المعاينة (Preview) تكتب في فرعها هي، فلا تمسّ بيانات `main`.
- `data/reports.json` — كل التقارير (الأحدث أولاً). يُضمَّن أيضاً داخل `index.html` كبيانات بداية.
- `src/app/` — قالب الصفحة (`template.html`) والتنسيق (`app.css`) والكود (`app.js`: التصميم بالمقاسات الثلاثة، اللوحة، الأرشيف، التصدير، الترجمات وقائمة المحافظات).
- `src/build_site.py` — يجمع ما سبق في `index.html` واحد.
- `src/assets/` — الصورة، الشعار، الخطوط، أيقونات [Phosphor](https://phosphoricons.com) (MIT)، ومكتبتا html2canvas و[fflate](https://github.com/101arrowz/fflate) (MIT).
- `src/design-source/` — ملف التصميم الأصلي (.dc.html) من Claude Design، للرجوع إليه فقط.

لإعادة توليد `index.html` بعد أي تعديل في `src/`:

```bash
pip install pillow segno   # segno لرمز QR في الستوري (اختياري)
cd src
python3 build_site.py
```

## تفعيل الحفظ المشترك بين الأجهزة (خطوة لمرة واحدة)

1. أنشئ **GitHub Personal Access Token** (من إعدادات حسابك على GitHub → Developer settings → Fine-grained tokens) بصلاحية **Contents: Read and write** على مستودع `MO3CODE/insani_durum` فقط.
2. في لوحة تحكم Vercel لمشروع `insani_durum`: **Settings → Environment Variables**، أضف:
   - `GITHUB_TOKEN` = التوكن من الخطوة السابقة.
   - `EDIT_PASSWORD` = كلمة مرور من اختيارك (تُطلب عند الحفظ لحماية البيانات من التخريب — يمكن تركها فارغة لتعطيل الحماية).
3. أعد نشر المشروع (Redeploy) بعد إضافة المتغيرات.
